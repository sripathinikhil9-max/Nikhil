# Revenue Audit Bot

Automation for AppSheet Revenue Audit workflow.

## Features

- Search BL
- Detect Found / Not Found
- Open Record
- Delete Existing Remarks
- Add Remarks
- Fill RA PIC
- Fill Auditor Remarks
- Fill Closure Remarks
- Click Settled
- Save
- Wait for Sync
- Update Google Sheet
- Batch Processing
